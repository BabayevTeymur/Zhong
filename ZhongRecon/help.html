Zhong – Network Reconnaissance Toolkit

Zhong is a LAN-focused reconnaissance and mapping tool that wraps nmap into a parallel, GUI-first workflow.

How to use

  1. Launch the Zhong GUI with python zhong_gui.py.
  2. Enter a CIDR subnet or a single IP and choose Subnet or Single host.
  3. Pick a profile (Fast/Balanced/Deep/Stealth) or check Full sweep (all ports) to send -p- for TCP/UDP.
  4. Toggle extras: OS detection, service/version detection, traceroute, OSINT lookup, WAN scan, DNS disabling, and custom nmap args.
  5. Click Start Scan. Live progress is shown in the log; once complete the results table and topology populate.
  6. Select any host to view open ports, vulnerability notes, traceroute hops, and OSINT data.
  7. Export as JSON/Markdown/HTML. Each export embeds the scan date/time and context metadata.

How it works

  • Zhong builds an nmap command using your discovery mode, timing, scan type, and port list (or -p- for full sweeps).
  • Discovery runs first unless single-host mode. TCP/UDP scans, OS detection, and optional OSINT are executed concurrently.
  • Traceroute collects every hop and the destination IP, which are drawn onto the topology map for path visualization.
  • Reports include raw scan details plus the generation timestamp so you can track when the data was produced.
